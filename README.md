# TaskMate

- AI task management for everyday work.
- Create tasks, projects, and simple checklists.
- Add tasks by typing, speaking, or uploading files.
- Turn big tasks into smaller next steps.
- Organize work by priority, energy, and due date.
- Use Today, Upcoming, search, and filters to stay focused.
- Sync tasks with Google and Outlook calendars.
- Work offline and sync when you reconnect.
- Keep your data secure with Supabase authentication.
- Track progress and unlock more AI features with a subscription.
